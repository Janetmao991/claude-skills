# Claude skills

Janet's own Claude Code skills, versioned so edits can be reviewed and rolled back.
What each skill does, and the projects they connect to, is in `~/claude-hq/REGISTRY.md`.

Only the skills whitelisted in `.gitignore` are tracked; installed third-party skills are not.
When you add a new skill of your own, add a `!/<name>/` line to `.gitignore` and commit it.
