# 拆解周刊：小红书图文版（Step 3.6，用户开口要时才做）

把深评做成一期中文图文轮播，发小红书。起因（用户 2026-11-06）：视频完播率太低，图文一页一个观点更容易划完。
第 1 期 Clay 是范例：`assets/weekly/example-clay/issue.html`（母版，13 页）+ `post.md`（发布文案）。新一期**复制这个母版改内容**，不要从零写 CSS。

## 落地位置

```
~/Startup Business Analysis/
├── render.sh                 导出脚本（缺了就从 assets/weekly/render.sh 复制）
└── <NN>-<company>/           NN = 期号，两位数；company 小写
    ├── issue.html            母版，全部页面在一个文件里
    ├── assets/               封面插图、图标（从公司官网取）
    ├── out/issue-pNN.png     成品，文件名顺序 = 上传顺序
    └── post.md               小红书标题、正文、话题
```

导出：`cd "$HOME/Startup Business Analysis" && ./render.sh <NN>-<company>`（headless Chrome，自动数页数；只导某几页就在后面加页码）。
**只保留最终版本**：样稿、备份、没用上的插图交付后移到废纸篓（用户 2026-11-07）。

## 格式

- 1080×1440（3:4），中文，一期 12–14 页。页码 `NN / 总页数` 在每页右下角（封面除外）。
- **封面用被拆公司自己的品牌风格**：官网的底色、主色、强调色，字体找免费近似款（Clay：奶油 #F4F3F0 / 森林绿 #035D44 / 荧光黄绿 #EEF773，Figtree + Instrument Serif 斜体）；中间放官网插图，角落标「插图：<域名>」；**不用公司 logo**（避免像官方出品）。
  - 封面标题是一句反差问句（"一条数据都不拥有，凭什么值 $7.1B"）。
  - **封面底部写公司简介**：一句话说清它是做什么的 + 4 个关键数（创立年份 / 客户数 / 年收入 / 估值）。不要写"01 02 03 看点"——很多读者根本不知道这家公司（用户 2026-11-07）。
- **内页用 Atlantic 风格**（用户在 Bloomberg / WSJ / Atlantic 三版样稿里选的）：白底，Noto Serif SC，红 #D7262B 只点最关键的一处，一页一个观点。
  - 标题 54px（用户嫌 72px 太大），正文 28px，图表做小、留位置给正文。
  - 用户也在意"一页能放的字太少"：正文 2–3 段为宜，底部留白超过 1/4 就补内容。

## 事实纪律（最高优先级）

- **每个数字和引语都要能在 Obsidian 研究文件里找到出处**（`Startup Deepdive/<公司>/` 或 `Podcast Research/<公司>/`）。不要从视频稿或其他二手稿转抄——Clay 那期视频稿把红杉原话 "data orchestration layer" 改写成"指挥家，不是乐团"，周刊又当原话引用，被核查出来（用户 2026-11-07）。
- 引语用原文翻译，署名到人和日期（"红杉资本合伙人 Alfred Lin，2024 年 6 月"）。帮助理解的比喻（游戏厅代币、买手）可以用，但不能挂在别人名下。
- 口头说法和书面说法冲突时，用书面的、范围更窄的那个（Clay 销售负责人说"老客户花费翻倍"，书面只说"大企业 NRR > 200%"）。
- 估算要注明（"Apollo 未上市，数字来自 Sacra 估算"）；派生数要写算法（"年收入 ÷ 客户数"）；时间段写实际起止，不照抄公司口号（"两年从 $1M 到 $100M"实际约 35 个月）。
- 交付前跑一遍逐条核对：把全刊的事实列出来，用脚本在研究文件夹里搜，查不到的要么找到出处要么删掉。

## 文字

- 定稿前用 **humanizer-zh** skill 全篇扫一遍（avoid-ai-writing 不支持中文）。Clay 那期常见问题：自问自答开头、"不是 X 而是 Y"、格言式收尾、破折号制造悬念、跨页重复同一句话（"Clay 不存数据"出现了三次）。
- 术语第一次出现就用白话解释，或打脚注；末页术语表收齐。
- 首字下沉（`p.dc`）的第一个字必须是汉字——英文单词会被拆成 "C / lay"。

## 组件（都在母版 CSS 里）

封面 `.cv`（`.top .brand .meta .pill h1 .serif .art .credit .bottom .intro .facts`）——每期按公司品牌改色值和字体。
内页 `section.page.atl`，可加 `.tight` 压缩列表行距。页内骨架：`.kick` → `h1` → `.dek` → `.by` → 内容 → `.notes` → `.folio`。
内容组件：
- `.body p` / `p.dc` 正文 / 首字下沉；`.lead` 红色小节标题
- `.qlist` 编号要点（斜体红数字 + 标题 + 说明）
- `.stats3` 三个大数字；`.bigstat` 一个大数字 + 解释
- `table.mt` 极简表；`table.mt.cmp` 对比表（`td.k` 行名，`.c` 本公司红色列，`.na` 未公开）
- `svg.grow` + `.cap` 折线图（客户/收入增长，最后一点用红色）
- `.dots` 点线图（倍数对比）；`.chain` 三节点流程；`.tl` 时间线；`.big30` 一个故事数字
- `.moats` 八格护城河（`.full` 已成立 / `.half` 建设中 / 空 = 没有）+ `.legend`
- `.pq` 引语（红色引号 + 署名）；`.notes` 脚注；`.gloss` 术语表；`.colophon` 来源

## 排版检查（每次导出后）

把全部页拼成联系表目检：
- 页序：同类页相邻，页码连续
- 每页：不溢出、不压页码、末行不只剩一两个字
- 表格、图表的数字标签不重叠
- 跨页不重复同一句话

## 发布文案 post.md

- 标题 ≤ 20 字，反差问句；给 2 个备选。
- 正文：第一段公司简介 + 最大的反差（估值 vs 收入 / 对手）→「这期从 N 个角度拆它」，按页序列出每个角度回答什么问题（不剧透答案）→ 提示末页有术语表 → 资料来源 + "本刊与 X 无合作关系" → 结尾一个具体问题。
- 话题标签 8–10 个：#创业 #startup #商业分析 #AI创业 + 赛道词 + 公司名 + #拆解周刊。
- 正文的数字也要能在周刊里找到，不新加事实。
