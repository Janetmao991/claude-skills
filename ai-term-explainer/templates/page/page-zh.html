Embedding 向量嵌入

顾客问"钱能要回来吗"，文档写的却是"退款"。一个字都对不上，电脑怎么知道这两句是一个意思？这页就讲这件事。

一句话记住：Embedding 是把东西变成"意义坐标"的那一步。有了坐标，才能按意思找东西、推荐、查异常。模型公司卖它，数据库存它，软件公司把它装进产品。

1
先给场景 · 不讲定义，先讲用在哪

一个客服机器人

假设你给公司做了一个客服机器人。公司有 500 份文档：退款流程、发货规则、会员说明……

顾客问
我买的东西不想要了，钱能要回来吗？
退款流程 · 500 份之一
发货规则
会员说明
…… 还有 497 份

机器人回答之前，得先从 500 份里，找到能回答的那一份。

2
再抛问题 · 没有它会卡在哪

按字找，找不到

最简单的办法是按字找（关键词搜索）。可顾客说的是"钱要回来"，文档写的是"退款"——一个字都对不上，什么都找不到。

所以电脑需要一种新能力：判断两句话的意思像不像。

3
讲原理 · 一个比喻讲透

意义地图

电脑不懂意思，但很会算数字。Embedding 把每句话变成一串数字，就像地图上的坐标：

"钱要回来" → [0.12, -0.83, 0.41, …]

意思相近的话，在地图上落在一起："退款""钱要回来""我要退货"挤在一个角落，"发货要几天"落在很远的另一个角落。判断像不像，就变成了量一量两个点离得多近。

分清三件事：Embedding 只是中间那一步

⓪ 训练：造翻译机

只做一次，在大家用它之前。靠"连连看"练：每一轮半成品模型也会出坐标，放错了就被纠正。
谁做：OpenAI、Voyage 这些模型公司

① Embedding：变成坐标

练好的翻译机把一句话（或一张图、一段声音）变成一串数字。
谁做：练好的 Embedding 模型

② 用坐标：量距离

找最近的（搜索）、推荐、查重、抓异常。
谁做：向量数据库、各种应用

就像给每个地方标上 GPS 坐标：⓪ 是培训会画地图的测绘员，① 是他给每家店标坐标，② 是别人拿着地图找附近的餐厅。坐标本身不会帮你找餐厅，但有了坐标，"找附近的"就变成了简单的算术。客服机器人"找到对的文档"，靠的是 ① 和 ② 一起；⓪ 早在开张前就做完了。

动手试试

为什么叫"向量嵌入"？

  • 向量（vector）：就是那串数字。
  • 嵌入（embed）：把一句话"放进"这张意义地图。

它不是新东西：2013 年 Google 的 word2vec 就把单个词放上了意义地图；今天的模型放的是整句话、整篇文档。

不只是文字

  • 图片：以图搜图、找相似商品（常用模型 CLIP）
  • 声音：先变成频谱图，再变成一串数字，"找相似的歌"就靠它
  • 商品、用户：推荐系统，"买了这个的人也买了……"

诚实的脚注：真实的那串数字有上千个（上千维），这里画成平面只是为了好懂。而且单看一个数字（比如 0.12）没有任何意义，意思只来自"哪些点离得近"。

4
讲用法 · 实际怎么用

三步

① 提前准备

把文档一段一段换成坐标，存起来。

② 顾客提问

把这句话也换成一个坐标。

③ 找最近的

离它最近的几段，交给 AI 去回答。

结果：电脑能按意思找东西了，顾客怎么说都行。推荐相似文章、找出重复内容，用的也是它；还能抓"异常"：离所有点都很远的那一个，可能是欺诈交易或设备故障。这套"先找资料再回答"的做法，行业里叫 RAG（见文末术语表）。

5
要自己做吗 · 不用，有现成的

一台现成的"翻译机"

把文字换成坐标，不用你自己做。有现成的 Embedding 模型，就像一台翻译机：你的程序通过 API 把文字发过去，它把那串数字发回来。OpenAI、Google 都提供这种服务，按 token（大约是"字数"）收费，很便宜。

算一算：把公司文档全部换成坐标要多少钱

按 OpenAI text-embedding-3-small 的价格 $0.02 / 百万 token 估算，只算一次性换坐标的费用。

7
讲门槛 · 做出来难在哪

原理不难，做到第一梯队很难

⓪ 训练阶段（造翻译机，只做一次）：它靠做"连连看"学会：意思相关的一对（"怎么退款？"↔"退款流程"）拉近；看着像、其实不对的（"怎么退款？"↔"退货地址"）推开。重复几亿次，它就学会了。

翻译机本身是什么？就是一个训练好的神经网络，去掉最后一层（原本输出答案的那层），它就不再给答案，而是吐出那串数字。

神经网络像一条流水线：前面几层接收原始输入，中间几层慢慢"理解"它，把它变成一串描述特征的数字，最后一层再把理解变成具体答案，比如"这是猫"或"下一个词是什么"。
拿一个分辨猫和狗的图片模型来说：正常用，它输出"猫，95%"；去掉最后一层，它输出 [0.12, -0.83, …]，也就是它对这张图的"印象"（尖耳朵、有毛、有胡须……）。两张不同的猫照片，印象会很像，在地图上就落得很近。
为什么要这么做？"猫还是狗"这个答案只能回答一个问题，而前一层的印象是通用的，拿来比相似、做搜索、做推荐都行。今天的文字 Embedding 模型（比如千问 Embedding）也一样：大模型最后一步本来是"猜下一个词"，跳过这一步，取它之前的那串数字，就是这句话的 Embedding。

常见疑问：大模型里不是也有 Embedding 吗？

有。大模型读文字的第一步，就是把每个字查字典换成编号（编号没有意思），再由第一层的 Embedding 层换成有意义的数字。这一层在训练开始时也是乱的，跟着大模型一起练准。但它和本页讲的 Embedding 模型不是一回事：

大模型里的 Embedding 层Embedding 模型（本页讲的）
在哪大模型的第一层独立的模型，常从大模型改造，取最后一层之前的数字
给谁坐标每个字 / 词各一个整句话、整篇文档一个
懂不懂上下文不懂，"退"在哪句话里坐标都一样懂，读完整句话才给坐标
用途让大模型自己读懂字，只在内部用拿出来比较：搜索、推荐、查重
能不能买不单独卖OpenAI、Voyage 等通过 API 卖

这些"对子"主要靠机器收集和 AI 生成，不是靠人工一句句标：

  • 微软的 E5：约 2.7 亿对（从网上的问答、标题-正文等配对里筛出来）
  • 阿里的千问 Embedding：用大模型自动生成了约 1.5 亿对
