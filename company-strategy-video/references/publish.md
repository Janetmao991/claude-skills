# 发布物料

全部放进这个 skill 的成片文件夹（company-strategy-video 是 `~/Technical Analysis/成片-公司策略/`，startup-intro-video 是 `~/Technical Analysis/成片-公司介绍/`），文件名都以公司名开头：

```
<公司>-<主题>-中文.mp4
<公司>-<主题>-封面-竖版.png
小红书文案.md
```

交付时把完整路径告诉 Janet，并把文案正文直接贴在回复里。

## 竖版封面（1080×1440）

Janet 确认小红书封面用竖版。用 `video/cover/cover-3x4.html` 改内容，然后：

```bash
cd video/remotion && node cover.mjs "$PWD/../cover/cover-3x4.html" "$HOME/Technical Analysis/成片-公司策略/<公司>-<主题>-封面-竖版.png"
```

- 主标题用本期的核心问题，两行之内，读得清（缩略图也要看得清）。
- 副标题一句话说清能得到什么（如"6 条值得学习的 GTM 策略"）。
- 下半部分放关键人物的真实访谈画面，抽帧选表情好的一帧，放 `cover/photo.jpg`。
- 颜色用这家公司的品牌色。
- 出图后用 Read 看一遍，确认标题没有换行错位、副标题没被挡住。

## 小红书文案

重点写**这个视频可以学到什么**：

```markdown
**标题（20 字内）**
和封面一致的问题句

**正文**
两三句背景：这家公司是什么、为什么值得看（用具体数字）。

这条视频拆解……看完能学到：

1️⃣ 主题：具体问题（带一个数字或悬念）
2️⃣ ……

最后一句说明素材来源，以及适合谁看。

**标签**
#...
```

- 每条写具体内容，不写空话，让人想点开找答案。
- 只写视频里真正讲到的内容，脚本改过之后要同步更新文案。
- 标题控制在 20 字内。
- 写完用 `humanizer-zh` 过一遍。
