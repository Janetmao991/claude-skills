# Report template — `<Company> — Tech Deep Dive.md` (Chinese, plain-language)

```
# <Company> — 技术实现拆解
> [!tip] TL;DR  —— N 层一句话流程 + 一句话判断(哪些是买来的零件、真功夫在哪、和 deepdive 护城河判断的关系)
研究日期 · 证据标签说明(✅ 已确认 / 🔍 推断 / ❓ 未知) · [[Deep Dive]] 等互链
## 0. 全景图   (ASCII 数据流,一个请求从头走到尾)
## 1..N. 第 k 层：<名字>   每层固定四段:
   **要解决的问题** / **<公司>怎么做的** ✅🔍 / **白话解释**(关键概念逐个解释,用生活比喻) / **为什么这么选 & 代价**(含创始人原话+出处)
## 安全:N 次漏洞 + 官司 —— 每件事都从架构解释成因,写出"教训"
## 成本:一次请求/一个用户每月多少钱 —— 表格 + 反直觉结论 + 它解释了哪些技术动作
## 回到投资视角:每层能被复制吗? —— 表(层 / 自研程度 / 被复制难度)+ 结论
## 你可以带走的:通用架构模式 —— 6–10 条,每条一句话 + 本公司例子
## 术语表 —— 按出现顺序,白话一句
## 还不知道的 ❓
## Sources —— 分组:本地证据 / 官方 / 招聘社区 / 播客 / 安全法律 / 定价
```
Writing rules: short sentences; every term explained at first use; numbers bolded; founder quotes with show + date; never present an inference as confirmed.
