# 画面方法

这是这个 skill 最重要的部分。参考 Janet 给的小红书视频：KAPI卡皮品牌研究社的 Touchland 拆解（`https://www.rednote.com/discovery/item/6ae8665f000000003302af49`）。它的画面几乎每个镜头都有真实素材，几秒换一次，看的时候不会觉得在读 PPT。

## 原则

**不把画面局限在书面的 PPT 描绘上。** 给一句台词选画面时，先想"这句话发生在哪里、谁说的、证据是什么"，能拍到、截到、找到的就用真实的。

每句话按这个顺序选：

| 这句话在讲什么 | 优先用的画面 |
|---|---|
| 人物观点、亲身经历 | 播客访谈画面、原声片段 |
| 事实、数字、结果 | 真实网页、新闻标题、人物原帖（逐字） |
| 品牌和氛围 | 公司自己的视频、官网元素、活动现场 |
| 用户行为、产品操作 | 产品实拍；没有就用 HTML 重建真实界面 |
| 因果、机制 | HTML 动画，让机制动起来 |
| 比喻、情绪，或完全没有素材的段落 | 生成图片 |
| 需要同时看几项对比或列表 | HTML 卡片 |

## 融入公司的特点

每一期的视觉从这家公司本身提取，不要沿用上一期的样子：

1. 打开官网和品牌素材，记下主色、字体气质、标志性元素（Clay 是黏土图标和森林绿）。
2. 把颜色写进 `src/episode/brand.ts`。
3. 下载官网的图标、插画、视频到 `public/web/`，官方 YouTube 频道的品牌片和产品演示到 `sources/broll/`。
4. 生成图也用同一套颜色和质感描述。

## 视觉主线（2026-11-16 加）

提取完颜色和素材后、给每句台词选画面之前，先定**一个属于这家公司的视觉想法，贯穿全片**。没有主线，每个画面单看都过得去，放在一起就像一堆通用信息图，换成任何一家公司都能用（Gamma 那期第一版审片员 C 的原话："全片没有一个属于 Gamma 的视觉想法贯穿下来"）。

主线从这家公司的产品或品牌本身来：

- Clay：黏土图标（官方的黏土动画角色），示意画面都用它们
- Gamma：整条片子像一份正在被 Gamma 生成的演示稿。网页截图放进深色舞台上的卡片里，示意动画也装进卡片、带生成时的那道光，屏幕一侧有页面缩略栏，五条策略是五页，讲到哪条亮哪条

定主线时检查三件事：

1. 它能不能同时解决版式问题（比如浅色截图和深色示意来回闪、出处标签压字）
2. 访谈和官方片仍然全屏，不是所有东西都塞进主线里，纪录片质感要留住
3. 一句话写进 `SCRIPT.md` 头部，审片员 C 的任务书里也要写上，它会检查主线有没有贯穿

## 画面不能停（硬规则，2026-11-16 加）

Gamma 那期 draft v4 有 31%（206 秒）的时间声音和字幕在走、画面停着，Janet："这个视频做的真的很差。"原因：用"等关键词才出下一个元素"的示意图替换了真实素材；示意图出完一个元素就停住；慢推幅度太小（4%），人眼看起来等于没动；渲染报的静止段被我当成"占位配音太慢"放过了。

- 每个镜头三层运动同时在：**载体**（整个镜头从第 0 帧推拉/平移到最后一帧，幅度要肉眼看得出，主卡片推 9% 左右）、**内容节拍**（元素跟着旁白出来，相邻两次变化间隔 ≤ 2 秒）、**环境**（光团漂移、星星闪、进度条走）
- 示意动画的元素要在整个镜头时长里持续推进，不能出完一个就停着等关键词；等不到就把镜头切短
- 能用真实素材（官方片、访谈、真实网页）就不用示意图，示意图是没有素材时的最后选择
- 渲染后必须跑 `tools/motion_check.py`（`render_full.sh` 会自动跑）：每秒比较画面变化，连续 ≥ 2 秒差值 < 1.5 就算停住。**有停住的段不交片**，不要拿"占位配音慢"当理由放过——判断时间要用正式配音

## 节奏

- 镜头几秒一换，长句用 `cuts` 在说到关键词时切换。
- 同一种素材不要连续用太久，也不要同一段视频反复出现。
- 一段素材只取需要的几秒。
- 硬切即可，配短促的 whoosh；重要数字可以加低音。

## 素材从哪来

| 素材 | 来源 |
|---|---|
| 访谈画面 | `podcast-dig` 找到的节目，用 yt-dlp 下载 65 秒窗口，静音画面当空镜 |
| 官方视频 | 公司 YouTube 频道（用 `yt-dlp --flat-playlist` 列出来），品牌片、产品演示、活动录像 |
| 网页证据 | `node shot.mjs`：官网、博客、定价页、新闻、职位页 |
| 历史版本 | Web Archive：`https://web.archive.org/web/<YYYYMMDD>000000/<url>` |
| 人物帖子 | vault 的社交媒体摘录，做成帖子卡，**原文逐字** |
| 社区讨论 | 公开论坛和活动页（Luma 等） |

下载或截图后一定要抽帧看：视频窗口开头可能是主持人，拉长后可能带进别的公司的幻灯片，页面可能已失效或被 cookie 弹窗挡住。

## HTML 画面

没有真实素材时才用，并且要做得像真实场景：

- **重建界面**：Slack 对话、发账单列表、LinkedIn 信息流。内容要贴合这句台词。
- **机制动画**：两种模式的对比、流程、多对一的汇聚、增长曲线、一圈圈向外扩张。

能用动作说明的就不要用文字说明。模板见 `references/production.md`。

重建或示意的画面在左上角标"示意"，不让观众误以为是真实截图。

## 生成图片

用在比喻、氛围，或确实没有素材的地方。本机已装 FLUX，一张 1280×720 约 1 分钟：

```bash
HF_HUB_DISABLE_XET=1 ~/.venvs/mflux/bin/mflux-generate \
  --model dhairyashil/FLUX.1-schnell-mflux-4bit --base-model schnell --low-ram \
  --steps 4 --width 1920 --height 1080 --seed 7 \
  --output remotion/public/gen/<名字>.png --prompt "..."
```

`--low-ram` 在 24GB 内存上必须加。

写提示词时：

- 同一期用统一的画风和颜色描述，把这段描述固定下来反复用。每个镜头换一种画风会有明显的 AI 拼贴感。
- 换 `--seed` 多试几张，挑最好的。
- 提示词里写 `no text`，这个模型写不好文字。

不要用生成图表现真实的人物、事件、产品界面或数据。观众可能把它当成真的，那是这类视频最不能出的问题。生成图在左上角标"示意"。

已知局限：构图和氛围好，但精确的品牌色和手工材质偏弱，所以公司的真实元素继续用官方素材。

## 画面上的文字

- **只有底部一条字幕**（中文加小号英文）。画面中间不放大字，Janet 否决过两次，缩小也不行。
- HTML 画面里的文字是标注，要短，每行放得下，不要出现单字换行。
- 真实素材的左上角可放小号出处标签，如 `web.archive.org · clay.com · 2021-09`。
- 不要在播客片段上加贴纸式的英文文字。

## 不要这样

- 整屏文字卡片，或奶油色背景上的一页页图解（Janet："还是有很多内容是在画 PPT"）
- 素材放得比镜头短，停在最后一帧
- 用不相关的画面凑数：讲"小单不配销售"时切到一篇无关的新闻页
- 用跟台词无关的漂亮画面，观众会分心
