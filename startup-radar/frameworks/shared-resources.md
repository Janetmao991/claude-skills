# 跨框架共享资源(2026-08-15 建)

三个 persona 之外的分析工具与数据源。**用法**:persona 在 [Framework] 段可以引用这里的框架来加强论证(标注来源机构),但 verdict 仍必须从各自的清单得出;信息收集(Step 1)可用这里的数据源。**所有 URL 已于 2026-08-15 验证可达。**

## 护城河 / 网络效应
- **NFX — The Network Effects Manual** — https://www.nfx.com/post/network-effects-manual
  16 种网络效应按强度分级(最强:Physical / Protocol / Personal Utility;强:Personal / Market Network / Hub-and-Spoke / Marketplace / Platform;中:Asymptotic Marketplace / Expertise / Data / Tech Performance;弱:Language / Belief / Bandwagon / Tribal)。**核心判据:使用增加是否让现有用户获得的价值增加**——网络效应 ≠ 病毒传播。a16z 清单第 3 项、Sequoia 第 3/6 项评估护城河时,先用这张表给"网络效应"定级,别笼统说"有网络效应"。
- **NFX — 70% of Value in Tech Is Driven by Network Effects** — https://www.nfx.com/post/70-percent-value-network-effects(量级校准)

## SaaS / 云 / 基准数据
- **Bessemer — Atlas**(总入口)— https://www.bvp.com/atlas
  BVP 的 SaaS/云/AI 基准报告库(State of the Cloud、AI 报告、Cloud 100 等)。评估 SaaS 型公司的增长率、NRR、毛利是否达标时,从这里取当年基准数字,标注 "(BVP Atlas, <year>)"。
- **SaaStr** — https://www.saastr.com/ (Jason Lemkin 的 SaaS 运营基准与常识:ARR 里程碑、销售效率、churn 经验值)

## 创始人 / 运营视角(补充 YC 的"人"的维度)
- **Elad Gil 博客** — https://blog.eladgil.com/ (High Growth Handbook 作者;规模化阶段的团队/董事会/融资判断)
- **Lenny's Newsletter** — https://www.lennysnewsletter.com/ (产品/增长实操,PMF 信号、留存基准;评估 consumer/prosumer 产品时用)

## 使用纪律
- 引用时写明来源机构(如 "(NFX network-effects taxonomy)"),不要把第三方框架混写成 YC/a16z/Sequoia 的观点。
- 基准数字必须带年份;过期基准(>2 年)只作方向参考。
- 新增资源前先 curl 验证 URL 存活,并在此文件记录添加日期。
